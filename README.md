# Civil Servant Evaluation System

A web-based system for managing and evaluating civil servant performance on a monthly evaluation basis.

The system is designed to help administrators manage civil servants, evaluation periods, attendance, work performance, behavior, and evaluation results in one centralized system.

---

## About the System

The **Civil Servant Evaluation System** is developed to simplify the monthly evaluation process for civil servants.

Instead of managing evaluations manually, administrators can use the system to:

- Manage organizations, departments, offices, and users
- Create and manage evaluation periods
- Select civil servants for evaluation
- Evaluate work performance
- Evaluate attendance
- Evaluate behavior and characteristics
- Preview evaluation results before submission
- Submit and store evaluations
- Track evaluation status
- View completed evaluations
- Calculate scores automatically
- Maintain evaluation history

The system is designed with a structured evaluation process so that each evaluation type can be managed and stored separately while remaining connected to the same evaluation period.

---

## Evaluation Types

The system currently supports three main evaluation types:

### 1. Work Performance

Evaluates the work achievements and performance of civil servants during the evaluation period.

### 2. Attendance

Evaluates attendance-related information such as:

- Approved leave
- Unapproved leave
- Late hours
- Early leave
- Attendance percentage
- Attendance score

The system also supports **perfect attendance**, meaning users with no attendance issues can be marked as having perfect attendance without entering unnecessary values.

### 3. Behavior

Evaluates characteristics such as:

- Behavior
- Initiative
- Leadership
- Other defined evaluation characteristics

## Main Features

### Authentication

- Secure login
- Session-based authentication
- Role-based access control
- Logout
- User profile
- Change password

### Organization Management

- Organizations
- Departments
- Offices
- Civil servants / users
- Positions
- User status

### Evaluation Period

Administrators can work with evaluation periods that contain:

- Start date
- End date
- Evaluation status
- Assigned users

Only an active/open evaluation period can be used for evaluation.

### Evaluation Management

Each evaluation is associated with:

- Evaluation period
- Evaluator
- Evaluatee
- Evaluation type
- Evaluation status
- Submission date
- Audit information
